03

면접을 위한 업계 인사이트

"요즘 업계 변화를 어떻게 보세요?" — 면접에서 꺼낼 수 있는 이야기를 매일 하나씩 쌓아드려요.

Config 2026 이후, 프로덕트 디자이너의 직무기술서가 바뀌고 있다

지난달 Figma Config 2026에서 Motion(타임라인 애니메이션), Weave(AI 이미지 워크플로우), Code Layers(디자인↔코드 양방향 변환)가 공개됐어요. After Effects 없이 프로덕션 수준 모션을 만들고, 캔버스에서 바로 GitHub 연동 프로토타입을 돌리는 게 표준 워크플로우가 되는 중이에요.

오늘 새로 나온 공고들에도 이미 반영되고 있어요. '프로토타이핑', '디자인 시스템', '데이터 기반 검증'이 자격요건 상단으로 올라왔죠. 디자이너에게 기대하는 역할이 '화면 그리는 사람'에서 인터랙션과 시스템을 설계하는 프로덕트 아키텍트로 이동하는 신호예요.

🎤 면접에서 이렇게 — "최근 주목한 업계 변화"를 묻는다면: Config 2026의 Code Layers로 디자인-개발 협업 경계가 바뀌는 점을 짚고, 내 프로젝트에서 프로토타입으로 검증한 경험 하나를 연결해 보세요.
